# AI-Powered-PostManager-Frontend
Build Web application that allows a business user to create and manage Google Business Profile.


## Project Overview

AI-Powered GBP Post Manager is a web application for creating and managing Google Business Profile posts.

Users can create posts, generate content using AI, save drafts, and mark posts as published.

## Features

1.User registration and login
2.Dashboard
3.Mock business locations
4.Create GBP posts
5.AI content generation
6.Edit generated content
7.Save posts as drafts
8.Publish posts
9.Search and filter posts
10.Edit and delete posts
